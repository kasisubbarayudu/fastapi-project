
## Testing:

Normally when we make any changes, whether it is implementing new feature or fixing bugs or modifying existing feature of a func, we have no idea if the changes we make break other functionality in our code.  Normally developers use postman, curl, or something and check every single scenario to make sure things are working as expected.


This is not scalable at all and will waste lot of hours to figure out what code we have broken. This is where we automation testing comes into play.
